PS5 CHAINS

Start with Relapse if it supports your firmware. The PS4 icon picker does not apply to PS5 payloads.

SET BOTH DNS FIELDS TO
2.28.132.105

On the PS5, open Settings, Network, Settings, Set Up Internet Connection. Open your connection's Advanced Settings and set DNS Settings to Manual. Enter this address for both Primary and Secondary DNS.

Then open Settings, User's Guide, Health and Safety, and Other Information, User's Guide. Open the PS5 tab and choose a hosted chain.

RELAPSE 7.00 – 13.60

Browser and kernel chain by ntfargo. Recommended first for supported firmware from 7.00 to 13.60.

Choose Jailbreak or Jailbreak & Load Payloads. After elfldr is ready, Load Payloads sends selections without another jailbreak. The defaults are exactly kstuff, etaHEN, and ShadowMountPlus. Payload Manager and four other payloads are optional; when selected, Payload Manager loads last. Successful sends are skipped on the next press.

Expect to retry: webkit can stall, and the kernel stage can hang or panic the console. Reload the page if the browser stops responding, and reboot before trying again if the kernel stage fails.

BROWSE

Enter a web address or hosted chain name, such as p2jb.

Which one is for my console? A devkit needs the devkit site — it sets target ID 0x81 and the debugger auth ID. Retail and testkit both take the ordinary site (target ID 0x82). Picking the wrong one just fails to jailbreak; it does not harm the console.
